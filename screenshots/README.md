# Fedora AutoTile Screenshots

This directory is reserved for genuine screenshots of **Fedora AutoTile** in action on GNOME Shell under Fedora Workstation.

---

## Guidelines for Adding Screenshots

To ensure screenshots in the documentation remain clean, authentic, and consistent, please follow these guidelines:

1. **Resolution & Scaling**:
   - Capture at native 1080p (1920x1080) or 1440p (2560x1440).
   - Use standard GNOME default fonts and default Adwaita/Adw styling.

2. **File Format & Optimization**:
   - Format: PNG (`.png`).
   - Optimize using `optipng` or `pngquant` to reduce file size before committing.

3. **Recommended File Names**:
   - `overview-dynamic-grid.png`: 4 tiled windows demonstrating the default Dynamic Grid layout.
   - `layout-master-stack.png`: Demonstration of the Master & Stack layout.
   - `top-panel-indicator.png`: Close-up of the GNOME top bar indicator menu with active layout selector.
   - `prefs-general.png`: Libadwaita Preferences window (General & Gaps tab).
   - `prefs-floating.png`: Libadwaita Preferences window (Application floating exceptions tab).

4. **Submission**:
   - Submit screenshots as part of a pull request.
   - Do **not** use AI-generated or mock UI screenshots.
