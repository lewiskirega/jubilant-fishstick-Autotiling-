# Security Policy

The Fedora AutoTile maintainers take security seriously. We appreciate responsible disclosure of any potential vulnerabilities.

---

## Supported Versions

Only the latest stable release receives security updates and patches:

| Version | Supported |
| :--- | :--- |
| `0.1.x` | :white_check_mark: |
| `< 0.1.0` | :x: |

---

## Reporting a Vulnerability

**Please do not report security vulnerabilities via public GitHub issues, discussions, or pull requests.**

Instead, please report potential security vulnerabilities privately through either:

1. **GitHub Private Vulnerability Reporting**:
   Navigate to the [Security Advisories tab](https://github.com/lewiskirega/fedora-autotile/security/advisories) on GitHub and click **"Report a vulnerability"**.
2. **Email**:
   Contact the maintainers directly at: **security@codefort.dev**

### What to Include in Your Report
Please provide:
- A description of the issue and its potential impact.
- Step-by-step instructions or proof-of-concept (PoC) code to reproduce the vulnerability safely.
- Affected GNOME Shell, GJS, or Fedora version(s).
- Any proposed remediation or mitigation.

### Response Timeline
- **Initial Response**: Within 48 hours acknowledging receipt of your report.
- **Assessment & Triage**: Within 5 business days with preliminary findings.
- **Fix & Disclosure**: We will collaborate with you to develop a patch and coordinate a public release alongside an advisory.
